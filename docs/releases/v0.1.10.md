# MuRingDevSetup-0.1.10-x64.exe

Orca WSL 자동 이름 생성 패치와 업데이트 후 누락 감시를 포함한 **Pre-release**입니다.

## 변경 내용

- Orca 이름 생성 패치에 Windows **1.4.215** 지원을 추가했습니다. 기존 1.4.202도 지원하며, 검증된 파일 해시가 일치할 때만 적용합니다.
- 백업을 버전별로 보관해 Orca 업데이트 후 이전 백업과 충돌하지 않습니다.
- 설치 구성에 **Orca 패치 누락 감시**를 추가했습니다. 기본 선택은 해제돼 있고 Orca 스킬·패치와 독립적으로 선택할 수 있습니다.
- 감시는 현재 Windows 사용자의 로그인 시와 5분마다 패치 상태를 확인합니다. 검증된 원본이면 누락을 알리고, 알 수 없는 버전이면 검토가 필요하다고 알립니다. 앱을 자동 수정·종료하거나 업데이트를 차단하지 않습니다.
- 감시 스크립트와 검증 데이터는 Orca 업데이트 폴더 밖에 보관합니다. 재실행 시 예약 작업과 파일을 확인하고 비활성화·누락·오래된 파일을 복구합니다.

## 실행 방법

Windows 로컬 폴더에서 `MuRingDevSetup-0.1.10-x64.exe`를 실행하고 환경을 확인한 뒤 필요한 항목을 선택합니다.
현재 PC에 패치가 적용돼 있어도 **Orca 패치 누락 감시**를 별도로 선택할 수 있습니다.
패치 적용에는 Orca 정상 종료가 필요하고, 설치기가 사용 중인 Orca를 자동 종료하지 않습니다.

감시 항목의 완료는 감시 설치 완료를 뜻하며 패치 적용 완료와 별개입니다.
Windows 알림 설정에 따라 표시가 억제될 수 있습니다. 결과는 `%LOCALAPPDATA%\MuRingDevSetup\OrcaPatchMonitor\status.json`에도 기록합니다.
선택 해제는 기존 감시를 제거하지 않습니다. 제거 명령은 저장소의 [패치 안내](https://github.com/Muring/muring-dev-setup/blob/main/windows/patches/README.md)를 참고하세요.

기존 설치 상태·설정 경로는 유지합니다. 0.1.9를 포함한 과거 배포 파일은 교체하지 않습니다.

## 검증 범위

- 앱 형식 검사, 단위 테스트 14개, TypeScript/Vite 빌드, Playwright UI 11개 통과.
- 콘텐츠 업데이트 10개, AI 워크플로 9개, 설치 순서·재시도·감시 독립 설치, 셸 설정 보존, KB 연결 검사 통과.
- Windows `app-host.ps1`, `wsl-location.ps1` 통과.
- 격리된 Windows 예약 작업으로 감시 설치·반복·비활성화 감지·스크립트/검증 데이터 손상 복구·제거 검사 통과. 실제 WSL 설치 단계로 현재 사용자의 감시 업데이트와 `-Check` 검증도 통과.
- Orca 1.4.202/1.4.215의 적용·복원·반복·잠금·미지원 파일·손상 백업 거부 및 감시 상태 검사는 이번 변경 과정에서 통과했습니다. 이후 패치 적용 스크립트는 변경하지 않았습니다.
- 현재 PC의 Orca 1.4.215에 패치를 적용하고 재시작한 뒤, WSL Codex의 실제 자동 이름 생성과 이전 오류 해제를 확인했습니다.
- 패키지 버전 0.1.10과 동봉된 Linux·Windows·공유 리소스 28개가 소스와 일치합니다.
- 최종 EXE를 Windows 로컬 폴더에서 격리된 LOCALAPPDATA로 실행했습니다. 앱 이름·버전, sandbox preload·IPC, 실제 WSL 환경 검사, GitHub 콘텐츠 미리보기, 설치 항목 22개, 감시 항목의 기본 선택 해제·선택 가능 상태와 고정 제목 스크롤을 확인했습니다. 화면 캡처도 확인했습니다.
- 최종 EXE의 Authenticode 상태는 NotSigned입니다.

신규 Windows VM의 WSL 설치·재부팅·Ubuntu 생성·전체 설치와 실제 향후 Orca 업데이트 후 알림은 미검증입니다.
서명되지 않은 Windows x64 포터블 빌드입니다.
