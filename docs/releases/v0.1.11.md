# MuRing Dev Setup 0.1.11

Orca 공식 업데이트로 사라진 WSL 이름 생성 패치를 다시 적용하는 **Orca 자동 재패치** 선택 항목을 추가했습니다.

- 엔진·검증 데이터·Windows Node 22.23.2 런타임과 라이선스를 EXE에 동봉합니다. 사용자에게 저장소 다운로드나 별도 Windows Node 설치를 요구하지 않습니다.
- 현재 사용자 예약 작업으로 실행하며 원본 백업·무결성·함수 동작 검증 후 적용합니다.
- 파일 잠금은 정상 종료까지 기다립니다. Orca를 강제 종료하거나 공식 업데이트를 막지 않습니다.
- 지원하지 않는 코드 구조는 변경하지 않고 알림으로 안내합니다. 모든 향후 버전의 자동 패치를 보장하지 않습니다.
- 설치 화면의 항목은 기본 선택 해제이며, 설치 완료와 현재 패치 적용 완료를 구분합니다. 기존 수동 패치·알림 전용 감시도 유지됩니다.
- 재설치 시 해당 자동화 프로세스만 종료하고 파일을 갱신합니다. 백업·영수증은 유지합니다.

## 검증

- 앱 형식 검사, 단위 검사 14개, TypeScript/Vite 빌드, UI 검사 11개 통과.
- 자동 패치 회귀 검사 6개 통과: ASAR 구조·함수 계약, 손상·미지원 파일 거부, 연속 업데이트, 백업·복원, 업데이트 경쟁, 내장 무결성 정책 보존.
- 실제 Windows 임시 앱에서 파일 잠금 중 원본 유지, 잠금 해제 후 자동 적용, 미등록 버전 2개 연속 처리, 복원, 미지원 구조 거부 통과.
- 격리된 Windows 예약 작업에서 외부 Node 없는 상주 실행, 재설치 시 이전 컨트롤러 종료, 비활성화·파일 누락·변경 감지와 복구, 제거 통과.
- 설치 순서 검사에서 외부 Windows Node 및 Orca 스킬 설치와 독립적인 선택 항목 실행 확인.
- 등록 회귀 검사(콘텐츠 업데이트·AI 워크플로·PDP·자동 패치)와 최종 산출물의 Windows 스모크 검사 통과.
- WSL UI 검사는 기존 사용자 브라우저 라이브러리 경로를 지정하여 실행함.
- 패키지의 Linux·Windows·공유 리소스 39개(전용 Node와 라이선스 포함)가 원본과 일치함.

신규 Windows 전체 설치와 미래의 실제 Orca 업데이트는 검증 범위에 포함하지 않습니다. 서명되지 않은 Windows x64 포터블 빌드입니다.

- 최종 EXE를 Windows 로컬 폴더와 격리된 설정 경로로 실행하여 버전 0.1.11, sandbox preload·IPC, 실제 WSL 검사, 콘텐츠 미리보기, 설치 항목 23개와 자동 재패치 선택 상태 확인. 화면 캡처도 확인함.
- 최종 portable EXE에서 실제로 추출된 리소스 39개도 소스와 일치함. Authenticode 상태 NotSigned.
