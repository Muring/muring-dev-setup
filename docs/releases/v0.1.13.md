# MuRing Dev Setup 0.1.13

Orca 자동 재패치가 PowerShell 창을 반복해서 띄우던 실행 방식을 수정했습니다. 초기 환경 조회에 실패했을 때 오류를 보여주고 다시 시도할 수 있습니다.

- 자동 재패치의 1분 반복 예약을 제거했습니다. 설치 직후와 로그인 때 콘솔 창 없이 한 번 시작합니다.
- 상주 감시기는 5초마다 파일 변경 여부만 확인하고, 시작 시와 업데이트 감지 시 검사·재패치합니다. 변경이 없으면 상태 파일도 다시 쓰지 않습니다.
- 재설치 시 기존 반복 예약을 제거하며, 이전 감시 프로세스가 완전히 종료된 뒤 실행 파일을 교체합니다.
- 파일 잠금 해제 대기, 백업·검증, 이미 수정된 코드 보존은 유지합니다. 감시기를 직접 종료하면 다음 로그인 또는 재설치 전까지 다시 시작하지 않습니다.
- 초기 환경 조회 실패 시 오류와 **다시 시도** 버튼을 표시합니다. 재시도는 초기 데이터를 다시 읽으며 설치 작업을 실행하지 않습니다.

## 사용 방법

새 PC에서는 EXE를 Windows 로컬 폴더에서 실행하고 환경 확인 → 설치 구성 → 설치 진행 순서로 진행합니다. 기존 PC에서 자동 재패치 실행 방식까지 바꾸려면 새 EXE의 **Orca 자동 재패치** 항목을 다시 설치하세요. 새 EXE 실행만으로 기존 예약 작업을 교체하지는 않습니다.

실패한 작업 기록은 `%LOCALAPPDATA%\dev-bootstrap\last-operation.json`, 자동 재패치 상태는 `%LOCALAPPDATA%\MuRingDevSetup\OrcaAutoPatch\state\auto-status.json`, 실행 로그는 같은 설치 폴더의 `controller.log`에서 확인할 수 있습니다. 다음 버전은 GitHub Releases에서 새 EXE를 받아 실행합니다.

## 검증

- 이번 세션의 자동 패치 단위 검사 11개와 Windows 설치·재설치·제거, 파일 잠금·연속 합성 업데이트·백업·복원 검사 통과. 이후 해당 코드 변경 없음.
- 현재 PC에 로그인 트리거 하나만 등록됨을 확인했고, 실행기·PowerShell·Node의 창 핸들은 모두 0이었습니다. 65초 동안 같은 컨트롤러 PID와 상태 파일 수정 시각을 유지했습니다.
- 콘텐츠 업데이트, 설치 순서, 셸 설정, 로컬 KB 설치 회귀 검사 통과.
- 앱 형식 검사, 단위 검사 14개, UI 검사 13개 통과. UI 검사는 기존 사용자 라이브러리 경로를 지정해 실행했습니다.
- 실제 Windows 읽기 전용 환경 검사, 인수·한글 전달, WSL 미설치 모의 검사, 설치 위치 검증, 격리된 알림 감시 예약 작업의 설치·복구·제거 검사 통과.
- 최종 EXE를 격리된 Windows 로컬 폴더에서 실행해 버전 0.1.13, sandbox preload·IPC, 실제 WSL 환경 조회, 콘텐츠 미리보기와 설치 구성 화면을 확인했습니다. 실제 추출된 리소스 43개의 SHA-256이 소스와 일치했습니다. Authenticode 상태는 NotSigned입니다.

신규 Windows 전체 설치·재부팅·인증, 실제 재로그인과 향후 공식 Orca 업데이트는 미검증입니다. 창이 순간적으로 깜박이지 않는지의 화면 관찰과 검증된 원본을 사용하는 수동 패치 검사는 이번 릴리스에서 별도로 수행하지 않았습니다.
