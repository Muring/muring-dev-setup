# MuRing Dev Setup 0.1.12

Orca 자동 재패치에 터미널 출력 복원 수정을 추가했습니다. 복원 데이터가 도착했는데 화면 배치가 지연되면 복원 불가로 오인하던 경로를 수정합니다.

- 이름 생성과 터미널 복원의 수정 상태를 각각 검사합니다.
- 공식 업데이트 또는 로컬 패치로 이미 수정된 코드가 확인되면 그 코드를 변경하지 않습니다.
- 수정 전 코드와 주변 동작이 정확히 일치할 때만 백업·검증 후 적용합니다. 판별할 수 없는 변경은 검토 알림으로 안내합니다.
- 이름 생성 전용 패치의 기존 영수증만으로 전체 수정 완료를 판단하지 않습니다.
- 엔진·검증 데이터·런타임은 EXE에 포함됩니다. 파일 잠금 해제까지 기다리며 Orca를 강제 종료하지 않습니다.

모든 터미널 출력 누락 원인을 해결하거나 자동 진단하는 기능은 아닙니다. 신규 Windows 전체 설치 및 미래의 실제 공식 업데이트는 미검증입니다.

## 검증

- 자동 패치 회귀 검사 10개 통과. 이미 수정된 복원 코드는 무변경, 이전 영수증은 새 대상 재검사, 미지원·중복·손상 대상은 거부.
- 실제 Orca 1.4.215 원본과 이름 생성만 패치한 파일에서 최종 결과가 검증된 터미널 복원 패치 해시와 일치. 현재 설치본은 두 수정 모두 이미 적용되어 파일 무변경 확인.
- 실제 Windows에서 잠금 해제 후 자동 적용, 연속 합성 업데이트, 백업·복원, 외부 Node 없는 설치·재설치·제거 통과.
- 현재 PC 상주 자동화를 새 엔진으로 교체한 뒤 두 기능 모두 already-fixed 확인. Orca를 종료하거나 재시작하지 않음.
- 앱 형식 검사, 단위 검사 14개, TypeScript/Vite 빌드, UI 검사 11개, 설치 순서 검사 통과.
- 동봉 리소스 42개가 원본과 일치함.

- 최종 EXE의 Windows 실행 검사 통과: 버전 0.1.12, IPC·실제 WSL 검사, 콘텐츠 미리보기, 23개 설치 항목 및 자동 재패치 선택 확인. 실제 추출 파일 42개의 해시가 소스와 일치하며 Authenticode 상태는 NotSigned입니다.
